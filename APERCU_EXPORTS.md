## 🎨 Palette de Couleurs

### Couleurs Principales
- **Bleu Principal**: `#2563eb` 🔵
  - Bordures
  - Titres H2
  - Référence
  - Boutons

- **Bleu Foncé**: `#1e3a8a` 🔷
  - Texte principal
  - Nom de l'entreprise
  - Titres

- **Orange Accent**: `#f59e0b` 🟠
  - Barre d'accent sous l'en-tête
  - Symboles H3 (▸)
  - Éléments de mise en évidence

- **Gris Clair**: `#64748b` ⚪
  - Texte secondaire
  - Sous-titres
  - Pied de page

- **Fond Clair**: `#f8fafc` ⬜
  - Zone métadonnées
  - Arrière-plan des sections

## 📐 Hiérarchie Typographique

### Titres

#### H1 - Titre Principal
```
┌─────────────────────────────────────────┐
│ # INTRODUCTION                          │
│ (Fond: #eff6ff, Bordure gauche: #2563eb)│
│ Taille: 16-18pt, Gras, MAJUSCULES      │
└─────────────────────────────────────────┘
```

#### H2 - Section
```
■ SECTION PRINCIPALE
═══════════════════════════════════════════
(Symbole: ■, Bordure inférieure: #2563eb)
Taille: 14-15pt, Gras, MAJUSCULES
```

#### H3 - Sous-section
```
▸ Sous-section
(Symbole: ▸ orange, Pas de bordure)
Taille: 12-13pt, Gras
```

### Corps de Texte
- **Taille**: 11pt
- **Police PDF**: DejaVu Sans
- **Police Word**: Calibri
- **Interligne**: 1.8-2.0
- **Alignement**: Justifié

## 📋 Éléments de Formatage

### Listes à Puces
```
• Premier point avec espacement
• Deuxième point bien espacé
• Troisième point lisible
```

### Listes Numérotées
```
1. Première étape
2. Deuxième étape
3. Troisième étape
```

### Texte Formaté
- **Gras**: `**texte**` → **texte en gras**
- **Souligné**: `__texte__` → texte souligné
- **Combiné**: `**__texte__**` → **texte gras et souligné**

## 📊 Comparaison PDF vs Word

| Caractéristique | PDF | Word |
|----------------|-----|------|
| **Format** | `.pdf` | `.doc` |
| **Taille** | 50-200 KB | 30-150 KB |
| **Génération** | 0.5-2s | 0.1-0.5s |
| **Logo** | ✅ Base64 | ✅ Base64 |
| **Éditable** | ❌ Non | ✅ Oui |
| **Impression** | ✅ Parfait | ✅ Bon |
| **Partage** | ✅ Universel | ⚠️ Nécessite Word |
| **Sécurité** | ✅ Haute | ⚠️ Moyenne |

## 🔍 Détails Techniques

### En-tête
- **Hauteur**: ~150-180px
- **Logo**: 60×60px avec bordure bleue
- **Référence**: Format `RAP-ANNÉE-XXXX`
- **Bordure**: 4px bleue + 4px orange

### Métadonnées
- **Fond**: Gris très clair (#f8fafc)
- **Bordure gauche**: 5px bleue
- **Padding**: 20-25px
- **Espacement**: 8-10px entre lignes

### Contenu
- **Largeur max**: 210mm (A4)
- **Padding**: 30-48px
- **Line-height**: 1.8-2.0
- **Orphans/Widows**: 3 lignes minimum

### Pied de page
- **Bordure supérieure**: 2px grise
- **Padding**: 20-25px
- **Alignement**: Centré
- **Taille**: 9pt
