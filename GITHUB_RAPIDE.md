# 🚀 Mettre sur GitHub - Version Ultra Rapide

## 📋 Commandes à Copier-Coller

### 1. Configuration (une seule fois)
```bash
git config --global user.name "Votre Nom"
git config --global user.email "votre.email@exemple.com"
```

### 2. Initialiser Git
```bash
git init
git add .
git commit -m "🎉 Initial commit - ChantierAI v1.0"
```

### 3. Créer le Repository sur GitHub
1. Aller sur https://github.com
2. Cliquer sur **"+"** → **"New repository"**
3. Nom : **chantierai**
4. Cliquer sur **"Create repository"**

### 4. Lier et Pousser
```bash
# ⚠️ REMPLACER "VOTRE-USERNAME" par votre vrai nom d'utilisateur GitHub !
git remote add origin https://github.com/VOTRE-USERNAME/chantierai.git
git branch -M main
git push -u origin main
```

## ✅ C'est Fait !

Votre projet est sur GitHub : `https://github.com/VOTRE-USERNAME/chantierai`

## 🔄 Après Modifications
